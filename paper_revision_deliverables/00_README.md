## Naming convention

All files use the pattern `<TopicOrFigureNumber>_<Description>.<ext>`, no spaces-only names, no version suffixes like "final2" — this folder itself is the final version. If a further round is needed, duplicate the whole folder with a date suffix (e.g. `paper_revision_deliverables_20260810/`) rather than editing files in place, so the review trail stays intact.
